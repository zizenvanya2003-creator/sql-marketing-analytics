# sql-marketing-analytics
# Маркетингова вітрина даних (SQL / BigQuery)

Проєкт містить SQL-запит для побудови єдиної маркетингової вітрини даних на основі сирих таблиць витрат, установок та доходів.

### Етапи розробки та методологія

#### **Етап 1. Збір та очистка вихідних даних**
* Спочатку взяв дані з `cost_table` і склав усі витрати за датами, джерелами, `campaign_id` та назвами кампаній через `SUM(cost)`.
* Далі обробив таблицю установок `non_org_installs_report`: згрупував дані за датою, джерелом, `campaign_id` та назвою кампанії і порахував кількість установок через `COUNT(*)`.
* Після цього окремо підсумував доходи з двох джерел — від покупок у додатку (`in_app_events_report`) та від реклами (`ad_revenue_raw`), згрупувавши їх за датою, джерелом і `campaign_id`.

#### **Етап 2. Зведення установок та обох типів доходів**
* Об'єднав три отримані набори даних (`installs`, `in_app_revenue`, `ad_revenue`) через `FULL JOIN`, щоб зберегти кампанії, які присутні лише в одному з джерел.
* Для приєднання `ad_revenue` використав накопичений ключ через `COALESCE(i.date, r.date) = a.date` та аналогічно для `media_source` і `campaign_id`. Це дозволило приєднати рекламний дохід навіть у випадку, коли відповідний запис відсутній у таблиці установок, але є в `in_app_revenue`.
* Для відсутніх числових значень використав `COALESCE(..., 0)`, щоб замість `NULL` отримати нуль.

#### **Етап 3. Зведення витрат з результатами кампаній**
* Об'єднав таблицю витрат `costs` із результатами `campaign_performance` через `FULL JOIN` за ключами `date`, `media_source` та `campaign_id`. Це дозволило зберегти у вітрині кампанії, які присутні лише у витратах або лише в даних про установки та доходи.
* Назву кампанії в `campaign_performance` залишив через `i.campaign_name`, тому якщо для певної кампанії немає запису в таблиці установок, значення залишається `NULL`. Це дозволяє бачити такі випадки та контролювати якість даних.

#### **Етап 4. Формування фінальної вітрини та розрахунок метрик**
У фінальній вибірці розраховано основні показники для оцінки ефективності рекламних кампаній:
* **Загальний дохід (`total_revenue`)** = дохід з покупок (`in_app_revenue`) + дохід з реклами (`ad_revenue`)
* **Прибуток (`profit`)** = загальний дохід − витрати (`total_cost`)
* **Окупність (`roas_percent`)** = `(total_revenue / total_cost) * 100`
* **Ціна установки (`cpi`)** = `total_cost / total_installs`

> **Примітка:** Для розрахунку ROAS та CPI використано функцію `SAFE_DIVIDE`, щоб уникнути помилки падіння запиту при діленні на нуль.

У результаті отримано єдину маркетингову вітрину для оцінки витрат, установок, доходів та окупності рекламних кампаній. Дані у фінальному результаті відсортовано за датою (`ORDER BY date DESC`) та загальним доходом (`total_revenue DESC`).
